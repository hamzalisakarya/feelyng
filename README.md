# Feelyng

Feelyng is a bilingual platform for personal support with electricity, gas, and internet services in Germany.

## Project structure

- `frontend/` — public landing page intended for deployment with GitHub Pages
- `backend/` — reserved for the planned backend; no Spring Boot project has been initialized yet

## Frontend

- HTML
- CSS
- Vanilla JavaScript
- German and Turkish support

## Backend (planned)

- Java
- Spring Boot
- PostgreSQL
- REST API
- Customer, Subscription, Commission, and Follow-up CRM

## Local preview

Serve the repository with a static web server and open `frontend/index.html`, or open that file directly in a browser.

## Deployment note

The frontend lives in `frontend/`. The GitHub Pages source must be configured to publish that directory before the current root-level deployment can be replaced.
